Base → Arc

Circle Gateway — the route that works today (CCTP-to-Arc is not live)
⏱️ Deposit needs Base finality (~15–20 min) before it can be bridged. Deposit → wait → Check → Bridge. After that the mint on Arc lands in seconds.
Non-custodial — every transaction is signed in your own wallet; this page never holds funds or keys. Arc is only exposed by Circle's API with the X-ARC-PRIVATE-MAINNET-ENABLED header, so this route is early/undocumented. Start small.
